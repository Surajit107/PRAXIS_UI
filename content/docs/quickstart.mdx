# Quickstart

## 1. Run the API

Start `PRAXIS_API` locally (default `http://localhost:8000`). Confirm the UI can reach it via `NEXT_PUBLIC_PRAXIS_API_URL`.

## 2. Health check

```bash
curl -s http://localhost:8000/health
```

Expect a JSON envelope with `success: true` and operational status fields.

## 3. First public request

Public collections do not require authentication:

```bash
curl -s "http://localhost:8000/api/v1/public/randomusers?page=1&limit=5"
```
