# Quickstart

## 1. Run the API

Use the live API for docs examples, or run `PRAXIS_API` locally and switch `NEXT_PUBLIC_PRAXIS_API_URL` in `.env`.

## 2. Health check

```bash
curl -s https://praxis-api-kjrf.onrender.com/health
```

Expect a JSON envelope with `success: true` and operational status fields.

## 3. First public request

Public collections do not require authentication:

```bash
curl -s "https://praxis-api-kjrf.onrender.com/api/v1/public/randomusers?page=1&limit=5"
```
