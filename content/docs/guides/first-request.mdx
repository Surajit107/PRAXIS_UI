# Making your first request

This guide fetches a short list of random users from the public API. No authentication required.

## Endpoint

`GET /api/v1/public/randomusers`

Query parameters: `page`, `limit` (strings in the OpenAPI schema — pass numeric strings).

## What to inspect

- HTTP status (expect `200` on success)
- Envelope fields: `success`, `statusCode`, `message`, `data`
- Pagination behaviour when you change `page` / `limit`
